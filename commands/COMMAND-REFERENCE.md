# Command Reference
- `pwd` — current directory
- `ls -la` — detailed file listing, including hidden files
- `mkdir -p` — create directories and parents
- `touch` — create empty file
- `cp`, `mv`, `rm` — copy, move/rename, remove
- `cat`, `head`, `tail` — display file contents
- `nano` — terminal text editor
- `wc -w` — count words
- `grep` — search text
- `chmod`, `chown` — change permissions and ownership
- `tar`, `gzip` — archive and compress
- `jobs`, `fg`, `kill` — manage jobs/processes
- `ps`, `top` — inspect processes
- `ip a`, `ping`, `ss`, `hostname` — networking checks
- `find` — search for files
- `apt`, `dpkg` — package management
- `df -h`, `free -h`, `uptime`, `who`, `lscpu` — system monitoring

Read commands carefully before deleting files or changing system configuration.
