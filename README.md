# Linux 10-Activity Practical Lab
GitHub-ready workflow for completing and documenting the ten Linux practical activities in your own Kali/Debian/Ubuntu VM.

## Activities
1. Navigation and file management
2. File viewing and editing
3. Permissions and ownership
4. Archiving and compression
5. Process management
6. Networking basics
7. Searching and finding
8. Package management
9. Bash scripting
10. System monitoring and logs

## Structure
- `docs/WORKFLOW.md` — commands and steps for all activities
- `docs/EVIDENCE-CHECKLIST.md` — screenshots to capture
- `docs/RESULTS-AND-REFLECTION.md` — record actual outcomes
- `commands/COMMAND-REFERENCE.md` — quick reference
- `scripts/hello.sh` — required example script
- `evidence/screenshots/` — place your own screenshots here
- `evidence/terminal-output/` — place sanitized output here

Run commands individually, verify results, and capture your own evidence. Do not upload credentials or unredacted sensitive logs. The `chmod 777` exercise is insecure; restore `chmod 640` afterward.
